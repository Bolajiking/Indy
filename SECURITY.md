# Security policy

## Reporting a vulnerability

Email security reports to support@chainfren.com with the subject line
`SECURITY: Indyfren`. Include reproduction steps, affected version or commit,
and impact. Do not publish proof-of-concept details, credentials, access tokens,
or private user data before receiving acknowledgement.

## Supported versions

Security fixes are applied to the current `main` branch and the currently
deployed public sandbox beta. Older commits are not supported.

## Response

We will acknowledge reports, assess severity, and coordinate remediation through
the private report channel. Public disclosure timing is agreed with the reporter
after a fix or mitigation is available.
